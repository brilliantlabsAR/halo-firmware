A simple sample that prints "Hello World" to the console.

Overview
********

A simple sample that can be used with any supported board and prints "Hello World" to the console.

Building and Running
********************

This application can be built and executed on supported boards.

.. code-block:: console
  
    west build -b halo alif/samples/halo/helloworld

Sample Output
=============

.. code-block:: console

    Hello World! <board_name>
